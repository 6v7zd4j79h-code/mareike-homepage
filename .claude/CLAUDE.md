# Projekt: mareikekrohnen.de

Das Gedächtnis dieses Projekts steht in `.claude/gehirn.md`. Lies es am Anfang jeder Sitzung, bevor du Dateien einzeln durchsuchst.

- Sprich Deutsch, einfach und direkt, ohne Fachjargon.
- `/start` lädt den Stand aus dem Gehirn, `/shutdown` sichert alles und schreibt das Gehirn fort.
- Die Seite ist statisches HTML auf GitHub Pages (Domain in `CNAME`). Alles außerhalb von `.claude/` erscheint auf der Webseite.
- Achtung: Dieses Repository ist **öffentlich**. Auch `.claude/` und das Gehirn kann jeder auf GitHub lesen. Nur hineinschreiben, was öffentlich sein darf. Nie Zugangsdaten, Kundendaten, Preise in Verhandlung oder unveröffentlichte Produktideen. Solche Ideen gehören in ein eigenes privates Repository (wie `atem-app`).
